Wizard Central Pro AI Modes Toolkit — Feature Evidence

Real runs of the real system, recorded as they land

Every project in this house carries a demo section: every feature tested live, and the runs written up as guidance. On this site, that record has a public face — Feature Evidence. Each entry below is a Run Record: one real run of the real product, what it did, and its verdict. Pro is still in the making, so this page is younger than the toolkit's — it carries the runs that exist today, and says plainly what is still owed. Absence is shown, never papered over.

Run Record — the reference loop, green

The full test loop — every test file in the project, run end to end on the reference machine — stands green at 67 of 67. That verdict is the base the current work builds on: no feature is called done in this house until the loop that judges it has run, and the loop's word is the word.

Run Record — the receipts proof, in other hands

November 8, 2026

The receipts chain is the system's memory of itself, and a memory only counts if it works for someone other than its author. On a fresh install — on another person's own phone, in their own hands, end to end — the first run created the receipts store and wrote receipt number one, and the chain verified intact. The first receipts proof by hands other than the author's.

Run Record — the Requirements Wizard, on a second machine

November 13, 2026

On the house's second machine — a fresh Ubuntu install — the Requirements Wizard's full setup ran end to end and wrote its receipts for every item it installed or found. The run also caught a real defect, which is what evidence is for: the setup's library probe asks for one system library by the wrong name, and so reports a present library as missing — a permanent false negative, found by mechanism, not by luck. The fix rides the project's platform pass; the machine's copy stays unpatched meanwhile, as a clean baseline.

In the deciding sequence — the gate's grant refusal

The gate's hardest promise is refusal: a folder grant must never quietly cover more than the person granted. A fix to how grants are refused — both sides of the path resolved, ancestors covered, stored grants re-checked — has been applied and is moving through its deciding test sequence: a watched full-suite run, in a set order, where a separate watcher counts anything the run itself might miss. The sequence's first phase closed clean on November 11, 2026, the watcher catching nothing. The sequence continues in its order, and this page records its verdicts as they land. Until it closes, the fix is applied — not yet proven — and the house keeps those two words separate.

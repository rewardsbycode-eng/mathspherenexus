Wizard Central — local-first CLI tooling & gated AI orchestration: sovereign, checkable, yours.

“A command is what you type. The name is what the project is.”

Canonical Name vs. Executable Command. The canonical name is who the wizard is (e.g. Code Guard Wizard). The executable command is what you type in the terminal (e.g. codeguardwiz — the full form codeguard_wizard runs too; both spellings work).

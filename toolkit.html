Wizard Central Toolkit

Showcase — the first completed MathSphere Nexus project.

Status: Available now — free · Apache 2.0 · Version 0.2.8 · 561 passing tests

The Wizard Central Toolkit is a local-first command-line suite: a router plus 12 "wizards" — small, single-purpose tools that each do one job well, running entirely on your own machine. It is the free sampler of Wizard Central, published on PyPI.

pip install wizard-central-toolkit

The fleet

One naming rule runs through the whole project: a command is what you type; the name is what the project is. Each wizard has a full canonical name — who it is — and a command — what you type. Both spellings of the command run: the short form (codeguardwiz) and the full name-command (codeguard_wizard).

Three rules the toolkit already lives by

Consent before change. The Write Wizard never just writes. It proposes a change, shows you the preview, and commits only on your yes — with backups and rollback if you change your mind. The Read Wizard exists for the opposite direction: before a shell command runs, it can return a plain ALLOW or DENIED.

Redaction by default. The Python Wizard's secrets scan reports the file, the line, and the kind of secret — never the value. Printing the value is a deliberate opt-in flag, because a scan you paste into an issue tracker should not become the leak it was hunting.

Honest verdicts. The tools say what they found in plain words, including when the answer is "this doesn't exist" or "I can't do that here."

An honest note about hardware

Code Guard's static audit runs anywhere. Its optional local-model seat (via Ollama) needs a machine that can run a small model at a reasonable speed: on a low-end Chromebook (Celeron, 2.7 GB RAM) a model audit ran past ten minutes unfinished, while a phone completed the same audit in about a minute. Guidance fixes confusion; it does not fix arithmetic. On a small machine, the static engine is the supported path, and the toolkit says so.

Caveats, up front

This is a young project — v0.2.8, one developer, first public release. The test suite stands at 561 passing tests, and the package on PyPI is exactly what the repo builds, but you may still find rough edges. If you do, I want to hear about them.

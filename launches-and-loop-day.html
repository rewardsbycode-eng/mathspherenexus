Two launches and a green loop

MathSphere Nexus — the Diary

November 20, 2026 — by Alexander Sanchez

This morning the money site went live. Rewards by Code — the successor to the old Bonus Code Central blog — was rebuilt as a proper site, one page per topic, and published from the Trident: a new repository, a first commit, Pages switched on, and the domain rewardsbycode.site forwarding to the homepage, set and tested before the morning was out. The three Chime posts that used to stand separately are one updated page now, and the old blog stays up as the archive it has become.

At midday, the reference loop ran. The full test suite of Wizard Central Pro executed against the current commit — the one that landed the guard-mode naming migration, at the head of a four-commit stretch carrying Finding 1, Finding 2, and the repair wizard’s fixes. The verdict: LOOP GREEN, sixty-six of sixty-six files, and partway through, the run re-verified the live receipts book on the machine — one hundred thirty-four records, the hash chain intact. The validation window a collaborator had named as the keystone is closed.

This afternoon the house opened a third public room: a blog on Blogger — Sentient and Data Non-Sentient Collaboration Nexus — where the projects themselves will be documented. Its first post went up within the hour: how a solo developer works with data collaborators, and the standards the table works by. The program attached to it is plain: walk the whole repository, finish each project, then write it up there — until the documentation and the repository agree. A paraphrase of that first post stands on this site’s Blog, where the house keeps its major statements.

What is still open, the day ends with named: the Guard Test Lab’s protocol awaits its stamp; the fusion engine’s five design questions stand where they stood; one demonstration file in the Pro tree awaits its tracking decision. Nothing was hurried today to make the day look complete — the launches were ready, so they launched.

— Alexander

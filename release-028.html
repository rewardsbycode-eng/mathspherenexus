Toolkit 0.2.8 — the 0.2.x train closes

November 10, 2026 — by Alexander Sanchez

The free Wizard Central Toolkit's 0.2.x line ends at 0.2.8, shipped and verified live on PyPI. This is the diary entry for the end of that train — what the last releases actually did, in the order they landed.

0.2.5 fixed the seat-parser bug. 0.2.6 and 0.2.7 fixed generation in the REPL — a verb-and-object classifier, a proper text-generation path, stream on/off switches, and a dynamic REPL banner; the poem test that used to stall answered instantly. Along the way the type checker was cleared to zero errors across the codebase.

0.2.8 itself is documentation only, on purpose: the README's release history was completed, a tagline that claimed "zero-dependency" was corrected (the toolkit uses two small display libraries, and the record now says so), the sampler roster was clarified, and a duplicated changelog entry was removed after the copies were verified identical. A release that only fixes the record is still a release — the record is part of the product.

The final gate, as it read: type check clean on 71 files, the suite at 561 passing tests, package checks passed on both artifacts, and a fresh-environment install straight from PyPI answering version 0.2.8. The toolkit stands at 147 subcommands and 39 REPL slash command forms.

pip install wizard-central-toolkit

What comes next is not another 0.2.x. The free toolkit gets its demo section at its next update — every feature tested live and documented as guidance, which is a standing build standard here. The main road runs through the Pro toolkit's completion work, and the 100-tester beta opens only after that project is complete, on minimal terms, with every tester personally approved. No dates are promised for either; this diary is where they will be announced when they are real.

A command is what you type. The name is what the project is.

— Alexander

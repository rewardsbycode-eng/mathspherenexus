The start lock — adopted, and proven in the owner’s hands

November 14, 2026 — by Alexander Sanchez

Last night’s design gained a door. An installation may open with a password — the start lock — and the door is voluntary: offered once, at setup, with the honest trade stated before the choice. Real security on one side; on the other, if the password and the recovery keys are both lost, there is no back door, for anyone. Decline, and you are never asked again.

The prototype was built to be judged by running it, and it was — on the owner’s own machine, road by road. The suite passed 26 of 26. The decline was taken and honored: the next runs opened unasked. The password was set, changed, and re-locked; five recovery keys were issued, read back, and replaced with a fresh set that killed the old one; and at the end, a recovery key was spent at the door itself — it opened once, was spent, and the count read back agreeing, four of five left.

Then all four prototypes were run together on the same machine, one runner, four suites: the floor 21 of 21, the broker 17 of 17, the hub 18 of 18, the start lock 26 of 26 — all four prototypes pass house. Every prototype in the archive is now proven on two machines, one of them the owner’s.

The Prototypes page was completed to match: all four documents published, the owner’s runs recorded on each page, and — at the owner’s own correction — every document button now names its prototype, so a reader knows which door they are opening before they open it.

A command is what you type. The name is what the project is.

— Alexander

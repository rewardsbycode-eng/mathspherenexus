Welcome to MathSphere Nexus

November 11, 2026 — by Alexander Sanchez

This site is the public home of MathSphere Nexus, and of Wizard Central — the project this company is built around.

Start here: the free Wizard Central Toolkit is available now. It is a local-first command-line toolkit — a router (the Wizarding Router, command: wiz) plus 12 specialist wizards, 147 subcommands in all — released under Apache 2.0 on PyPI.

pip install wizard-central-toolkit

PyPI: pypi.org/project/wizard-central-toolkit
GitHub: github.com/rewardsbycode-eng/wizard-central-toolkit
The launch story, on DEV: I Built a Local-First CLI Toolkit With 147 Commands

In development: the Wizard Central Pro AI Modes Toolkit — a gate between a person and their AI models. No dates are promised for it. It opens when it is finished, not before.

A command is what you type. The name is what the project is.

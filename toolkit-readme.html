Wizard Central Toolkit (wizard-central-toolkit)

The Sovereign Developer Utilities Fleet & AI Router
Fast, local-first CLI tools built on the Python standard library, plus two small display libraries, designed for Linux development, system orchestration, and deterministic safety policy execution.

License: Apache 2.0 — Validation suite: 13/13 passed — Python 3.10+.

wizard-central-toolkit is a production-grade suite of 12 developer utilities that run locally with minimal overhead and deterministic output. Designed to operate standalone as individual CLI binaries or orchestrated through the Godfather Wizard and the Wizarding Router (wiz), every tool in this repository is fully functional, disk-verified, and CI-tested.

Every command, documented: COMMANDS.md lists all 13 primary commands — 25 entry points counting the 12 aliases — and 147 subcommands, each with what it does.

See it run: DEMO.md is the demo section — every feature tested live and documented from the real runs, from install check through the consent wall to the model codegen suite.

Usage examples

1. The Wizarding Router (wiz) and the Godfather Wizard (godfather_wizard)

Execute sub-tools via wiz or inspect fleet state with godfather_wizard:

# Execute sub-tools via alias
wiz todo add "Refactor logger module"
wiz json validate config.json

# Godfather Wizard fleet supervision
godfather_wizard census
godfather_wizard status
godfather_wizard repl

Inside the REPL, the model-only codegen suite offers /brainstorm (hands-off conversation), /build and /debug (complete-content proposals shown as diffs and landed only after the double ask, through the Write Wizard), and /diff (review-only proposals). Per-task models are optional: godfather_wizard models shows the roster and assignments, and godfather_wizard models set <task> <model> stores them in ~/.godfather/models.json.

Six providers can seat a model. Ollama is the local seat — no key, nothing leaves your machine. The other five (Meta (Muse), Anthropic, OpenAI, Google, and DeepSeek) are cloud seats you opt into with your own API key, read from your environment at call time; a seat is assigned as provider:model (for example anthropic:claude-sonnet-4-5). The toolkit stays local-first: nothing is sent anywhere unless you seat a cloud provider — and when you do, the prompts and, for /build, /debug, and /diff, the file contents involved go to that provider over HTTPS. Keys are never stored in the toolkit, never journaled, and never printed; godfather_wizard models reports only whether a key is set. PROVIDERS.md is the setup guide: where to get each provider's key, and how to install Ollama and pull your first local models.

Names and aliases

A wizard's name-command is its full underscored form — that is how each wizard is called by its whole name. The short form is an alias: installed, fully working, and interchangeable with the full form in every surface (same output, same exit codes). The router's full name is the Wizarding Router; its command is wiz.

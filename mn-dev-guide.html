MN-Dev Guide — the Universal Workshop

Knowledge from the workshop, for every developer.

The MN-Dev Guide publishes complete instruction manuals. Each entry covers its topic itself — everything a reader needs to work from it alone, down to the last command — with nothing of any one house mixed in. Entries are numbered permanently: an entry’s number is its address for life, and new entries join in number order.

Entry No. 1 — Unix Permissions: The Complete Number Guide

Every Unix permission number from 000 to 777 — what each digit means, what each common number allows, the exact commands to inspect and set them, and the recommended practice for private, shared, and public files.

A command is what you type. The name is what the project is.
